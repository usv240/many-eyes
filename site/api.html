Use the engine in your own tools.

Any app that collects votes, from a Discord bot to a mapping event, can send them to Many Eyes and get back validated labels, refusals, accuracy on hidden checks and map-ready GeoJSON. Request a key, send one request, read the answer. You can do all three on this page.

Try it live

Pick where requests go. The sandbox runs the real engine inside this page, so it always works. If you run the server yourself with npm run demo, choose your server and the same requests go over HTTP.

Reference

Method and pathWhat it doesAuth
POST /v1/keysIssues a key. Shown once, stored only as a SHA-256 hash. Five per hour per address.None
POST /v1/decideDecides a batch of up to 5,000 tiles and 200,000 votes. Sixty requests per minute per key.Bearer key
GET /v1/healthService status.None
GET /v1/openapi.jsonThe full OpenAPI 3.1 description.None

Request

  • tiles: a list of tiles, decided in order.
  • id: any unique text up to 128 characters.
  • votes: { "user": "...", "vote": "1" }. A vote is 1, 2, 3, destroyed, intact or unsure. A later vote from the same user replaces the earlier one.
  • truth, optional: the known answer. It makes the tile a hidden check that measures accuracy and adjusts weights for the tiles after it.
  • lon and lat, optional: include the tile in the GeoJSON.

Response

  • tiles: status validated or refused, the label, agreement, voters, the reason for a refusal, the unweighted result for comparison, and the hidden check outcome.
  • summary: counts, and accuracy on hidden checks with and without weighting.
  • weights: each voter's final weight.
  • geojson: a FeatureCollection of tiles that had coordinates.
  • Errors: 400 with a list of issues, 401 for a missing key, 429 with Retry-After when rate limited.

Run your own server

The API ships with the stream server. Start it, request a key, and call it from anything that speaks HTTP. Keys are stored as hashes in data/api-keys.json.

npm run demo
curl -X POST http://127.0.0.1:8791/v1/keys \
  -H "Content-Type: application/json" -d '{"name":"my-app"}'
curl -X POST http://127.0.0.1:8791/v1/decide \
  -H "Authorization: Bearer me_..." \
  -H "Content-Type: application/json" \
  -d @votes.json

Many Eyes

The API, the stream and the data page share one engine: weighted agreement of at least 66% from at least 3 voters validates a label; anything else is refused. Code under the MIT licence.
